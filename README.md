## 多模型同名骨骼隔离

当同一个实体同时挂本体模型和技能模型时，如果多个模型里存在同名骨骼，动作可能串到另一个模型上。编辑器导出时会默认开启“普通同名骨骼隔离”，把非主模型的重复骨骼自动改成 `ba_模型资源key_骨骼名`，并同步改写对应 animation.json 里的 bones 键。

默认模型资源 `default` 会优先保留原骨骼名，额外模型资源会被改名。所有业务模型里原本叫 `root` 的骨骼都会被改名，因为导出模型最外层会强制包一个新的 `root`，用于整体缩放动画。

## 动画控制器目标模型资源

动画控制器卡片里的“目标模型资源”只影响导出时动画 bones 应该套用哪一份模型骨骼改名表，不会写入 yml，也不会改导入时的源文件。

默认选择“自动推断”：例如动作槽位 `skill1A`、`idleA`、`walkA` 会自动指向模型资源 key `a`。如果你的动作命名没有后缀，或者某个控制器应该强制作用到某个技能模型，就手动选择对应模型资源 key。
